STL units: nm. Carbon z=0..5 nm; copper z=0..10000 nm.
STL files are stored in nion/usim_device/samples/ relative to the repository root.
Smoothed signed-distance contours use subpixel coordinates, not voxel steps.
Carbon components and enclosed hole counts are checked against the original.
STL contains no material labels; separate files identify carbon and copper.
